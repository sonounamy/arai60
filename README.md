# arai60

[LeetCode](https://leetcode.com) の問題集 [Arai60](https://1kohei1.com/leetcode/) を使ったコーディング練習のリポジトリ。

---

## 進め方

### ブランチ運用

問題ごとにブランチを切って作業し、`main` へ PR を出す。

ブランチ名の形式：
```
{問題番号}/{問題名}
```

例：`387/First-Unique-Character-in-a-String`

### ファイル構成

問題の解答・メモは `problems/{問題番号}/` 以下に置く。

```
problems/
└── 387/
    └── memo.md
```

### 各問題の取り組み方

**step 1**
- LeetCode で問題を読んで、自力で解く
- 解けなくても一定時間（目安30分）で切り上げる
- コードと気づきを `memo.md` に記録する

**step 2**
- 他の人の解答や解説を読む
- 気づいたことや別解を `memo.md` に追記する

**step 3**
- 何も見ずにもう一度解く
- スムーズに書けるようになったら完了

### PR の出し方

- ブランチを push して PR を作成
- タイトルは `{問題番号} {問題名}`（例：`387 First Unique Character in a String`）
- レビューは任意、自分用メモとして活用してもよい

---

## diary

`diary/` フォルダに学習記録や気づきをまとめる。  
ファイル名は `YYYY-MM-DD.md` 形式。
